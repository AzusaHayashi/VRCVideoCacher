打开安装说明

安装速览
  1. Chrome：chrome://extensions → 打开“开发者模式” → “加载已解压的扩展程序” → 选择 browser-extension/ 目录。
  2. Firefox 138+：about:debugging#/runtime/this-firefox → “临时载入附加组件” → 选择本目录下的 manifest.json。
  3. 运行管理器安装 Native Host，并确认 allowed_origins 含本页显示的扩展 ID（chrome-extension://<id>/）。
  4. 登录 YouTube，点击“立即同步”；徽章变绿即表示 Cookie 已写入 %APPDATA%\VRCVideoCacher\youtube_cookies.txt。
